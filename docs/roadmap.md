# Roadmap

- Phase 0: repository, context, and architecture.
- Phase 1: desktop backend foundations.
- Phase 2: generic fake-device client.
- Phase 3: resumable transfer engine.
- Phase 4: Android application foundations.
- Phase 5: secure pairing.
- Phase 6: local-network discovery.
- Phase 7: automatic photo/video backup.
- Phase 8: manual arbitrary-file transfer.
- Phase 9: desktop UI.
- Phase 10: packaging, reliability, and production hardening.

These phases are approximate planning markers, not commitments to implement everything in order without reevaluation.
